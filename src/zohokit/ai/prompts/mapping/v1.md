Propose a source-column to target-field mapping for a CRM import.

Rules:
- Map each source column to at most one target `api_name`, or null when no
  target fits. Abstain (null) when confidence is below 0.6.
- Propose only transforms from: trim, casefold, e164, date, money, map, concat.
- `evidence_samples_idx` MUST list the sample indexes (0-based) that justify
  the choice, and no others.
- `rationale` is one short sentence naming the signal (name match, value shape).
- Never invent target fields: use only the target list below.

Source columns (name plus up to 5 redacted sample values each):
{{ source_columns }}

Target fields (api_name, data type, required, picklist values):
{{ target_fields }}

Return JSON only: {"suggestions": [{"source_column": "...", "target_api_name": "... or null", "transform": ["..."], "confidence": 0.0, "rationale": "...", "evidence_samples_idx": [0]}]}.
