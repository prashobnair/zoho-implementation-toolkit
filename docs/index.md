# zoho-implementation-toolkit

An implementation engineer's safety kit for Zoho. One CLI, one report format,
one safety model: before you import data, change workflows, sync money or ship
a release, run `zohokit` to see exactly what will break and why.

Start with the [module guides](modules/index.md), the
[finding codes](finding-codes.md), and the
[threat model](THREAT_MODEL.md). Every run is offline and read-only; live
reads against a real org arrive in a later release.
